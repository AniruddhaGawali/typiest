Privacy Policy for Typiest

Last Updated: December 28, 2024

Typiest is committed to providing a transparent and secure experience. This Privacy Policy explains how our Chrome Extension handles information.

1. Data Collection

Typiest does not collect, store, or transmit any personally identifiable information (PII) to external servers. All operations happen locally on your device.

  • Keystroke Data: When you use the extension to practice typing, your keystrokes are processed in real-time to calculate your speed (WPM) and accuracy. This data is never saved or shared.
  • Website Content: The extension reads the text of paragraphs you select on a webpage solely to create the typing overlay. This content is never uploaded or stored.

2. Permissions Usage

  • activeTab: Used to allow you to interact with the specific page you are currently viewing.
  • scripting: Used to inject the typing interface and comparison logic into the page.

3. Data Third-Party Sharing

We do not sell, trade, or transfer any user data to third parties. There is no background tracking or advertising code included in this extension.

4. Changes to This Policy

We may update our Privacy Policy from time to time. Any changes will be posted on this page.

If you have any questions about this Privacy Policy, you can contact the developer via the GitHub repository or Chrome Web Store support page.
